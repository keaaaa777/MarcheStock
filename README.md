# Marche Stock

作家・マルシェ出展向けのローカル在庫管理アプリです。

## 利用者向け：Windowsで起動する

### インストーラー版

1. `dist/Marche-Stock-Installer-1.0.0-x64.exe` を実行します。
2. インストール先を選びます。
3. デスクトップまたはスタートメニューの **Marche Stock** から起動します。

### ポータブル版

`dist/Marche-Stock-Portable-1.0.0-x64.exe` をダブルクリックして起動します。

ポータブル版はインストール不要です。USBメモリなどに置いて起動することもできます。

## 利用者向け：MacBookで起動する

MacBook上で生成した `.dmg` を開き、Marche Stockを `Applications` フォルダへドラッグして起動します。

初回起動時に「開発元を確認できません」と表示された場合は、FinderでアプリをControlキーを押しながらクリックし、**開く**を選択してください。

Mac用ファイルは、MacBookの種類に応じて次のいずれかを使用します。

- Apple Silicon（M1／M2／M3／M4）：`arm64`
- Intel：`x64`
- どちらでも動く版：`universal`

## 開発者向け：ローカル起動

Node.jsをインストールしたあと、プロジェクトフォルダで実行します。

```bash
npm install
npm run desktop
```

ブラウザ版として確認する場合は、次のコマンドを使用します。

```bash
npm start
```

その後、ブラウザで `http://localhost:4173/` を開きます。

## 配布ファイルの作成

### Windows用

Windows上で実行します。

```bash
npm install
npm run dist:win
```

`dist` フォルダに次の2種類が生成されます。

- `Marche-Stock-Installer-1.0.0-x64.exe`：インストーラー版
- `Marche-Stock-Portable-1.0.0-x64.exe`：インストール不要のポータブル版

### Mac用

MacBook上で実行します。

```bash
npm install
npm run dist:mac
```

MacBookのCPUに対応した `.dmg` と `.zip` が `dist` フォルダに生成されます。

Apple SiliconとIntelの両方に対応するユニバーサル版を作る場合は、次を実行します。

```bash
npm run dist:mac:universal
```

## データ保存について

データはアプリ専用のローカル領域に保存されます。インターネットや外部サーバーへの送信は行いません。

画面上部の以下の機能でデータを移行・退避できます。

- **JSON出力**：現在のデータをバックアップファイルとして保存
- **JSON取込**：別のPCや別のアプリ環境からデータを復元
- **バックアップ復元**：アプリ内の直近バックアップから復元

ブラウザ版で登録したデータをexe版へ移行する場合は、先にブラウザ版でJSON出力し、exe版でJSON取込を実行してください。

## 管理・集計機能

「管理・集計」画面から、次の機能を利用できます。

- 在庫調整・棚卸し履歴
- 仕入先別集計、月別・イベント別売上集計
- 販売・部品・商品CSV出力
- 直近販売のレシート印刷
- 商品コード／バーコード検索、ローカルQRコード生成
- 操作ログ、直前操作の取り消し
- バックアップ履歴から任意世代の復元
- 保存状態と保存データ容量の表示

## 優先度Aで追加した画面

- 仕入・入荷：部品の入荷、仕入先、数量、単価を登録し、在庫と平均単価へ反映
- 在庫履歴：仕入れ、販売、製作、棚卸し・調整を時系列で確認
- 販売履歴から各販売のレシートを再印刷
- ホームの売上グラフを直近6か月・今年・全期間で切り替え
- データ管理：JSON入出力、バックアップ復元、保存容量、操作ガイドを集約

本アプリは個人利用を前提としており、複数ユーザー・権限管理は行いません。

## 注意事項

- Windows版は現在x64向けです。
- Mac用の最終パッケージはMacBook上で生成してください。
- アプリをアンインストールすると、アプリ本体とデータの扱いが分かれる場合があります。重要なデータは定期的にJSON出力してください。
- Mac／Windows間でデータは自動同期されません。JSONバックアップを使って移行します。

## 操作チュートリアル

初回起動時は、画面上の「操作ガイドを始める」から、実際の入力欄と保存ボタンを順番に操作するチュートリアルを開始できます。

- 「ここをクリック」「ここに入力」の対象が画面上で強調表示されます。
- 入力内容が空のままでは次へ進めません。
- 途中で「スキップ」できます。
- 完了後も画面上部の「操作ガイド」からいつでも再実行できます。
- チュートリアルで保存した内容は通常のデータとして保存されるため、不要な場合は各管理画面から削除してください。
